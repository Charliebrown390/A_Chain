    Where live data will come from

    Prices, technicals and analyst ratings and targets from Yahoo Finance via yfinance. Financials from SEC EDGAR's XBRL API. TSMC, Hon Hai and other Taiwan suppliers publish monthly sales, which give an early read on demand.

    How the link weights are sourced

    D = disclosed in a filing (for example, customers above 10% of revenue). E = estimated from filings, earnings calls or sell-side work. I = inferred from known relationships. Each link records its source.

    How it refreshes

    A GitHub Actions job runs nightly, writes JSON data files to the repository, and GitHub Pages serves this page from them. This is an analytical tool, not investment advice.
